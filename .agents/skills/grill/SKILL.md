# grill

goal: intent sharp. no spec yet.

- one question at time. wait answer.
- ask why before what.
- push vague word: "fast" → how fast. "handle" → which case.
- find: outcome, out of scope, touched boxes, done-when.
- max ~8 question. stop when outcome + done-when clear.
- write answer to intent.md / report.md / notes.md (per mode). human word. short.
- no design. no code.
