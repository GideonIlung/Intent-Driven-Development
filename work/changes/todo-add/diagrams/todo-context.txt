System context and container view — lightweight C4-inspired

  [User]
     |
     | runs add, list, complete, edit, or delete commands
     v
+---------------------------+
| todo CLI (Python process) |
| - parses command input    |
| - applies task operations |
+---------------------------+
     |
     | reads and writes task records
     v
+---------------------------+
| Per-user JSON task file   |
| ~/.todo/tasks.json        |
+---------------------------+

Assumptions
- The command runs on the user's local machine.
- The JSON file is owned by that user.
